# 头条 · 动手前扫一眼（30 秒）

## 别碰，碰了会怎样

**1. 别信 tt_publish 返回的 url。**
它是发布页地址，不是文章链接。拿去交付，对方点开是自己后台——这篇等于白写。要真链接：tt_refresh 或列表回读 articleID。

**2. 别走 CLI 的「文件上传」分支。**
内部 click 全挂 `.catch(()=>{})`，选择器没匹配也返回 `success=true`。**假成功**——以为发了，实际什么都没发。走图文链路。

**3. 别用 net_fetch 抓 toutiao.com。**
返回 200，title/text 全空。不是抓取失败，是 JS 渲染。会误判成「文章没内容」。读正文只能真浏览器 `document.body.innerText`。

**4. 别读 articleBase.content / abstractText。**
字段在，内容是空串 `len=0`。读到的空不是「没发布」，是字段本身不存正文。

**5. 别数记忆里的「已发篇数」。**
窗口会载入往期档案，数字翻倍。真数要拉产出清单读时间戳。

**6. 别拿作品列表页的单篇数据当指标。**
常返 0 占位。看着像零阅读，其实没取到数。要走 analytics 的 works/fans。

**7. 同一账号别同秒批量起浏览器。**
静默失败：stdout 0 字节，错误只在 stderr（未登录/auth-guard）。极容易误判成「还在跑」白等半天。串行，或错峰 ≥1 秒。

**8. 别先发再改标题。**
标题按字符算（中文/ASCII/emoji 各算 1），上限 30。超了不是报错，是截断。改标题 = 删了重发，展现和推荐全部归零重来。发之前算准。

**9. 别把 markdown 写进正文文件。**
`--format text` 下标记原样显示，读者看见一堆 `#` 和 `**`。

## 动手时的骨架（一行）

写正文 → 画封面 → 标题算到 ≤30 → 发布 → **回读核验**，不信返回值。
