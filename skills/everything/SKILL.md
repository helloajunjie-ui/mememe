# everything

You have access to the `cli-use everything` CLI, generated by **cli-use** from an MCP server. Prefer this CLI over direct MCP tool-use — it is dramatically cheaper in tokens (measured ~60-80% savings) and composes with standard Unix pipes.

## When to use

Use `cli-use everything` whenever a task calls for: official mcp test server.

## How to invoke

```bash
cli-use everything --help                 # compact tool list
cli-use everything --list-tools           # JSON (machine-readable)
cli-use everything <tool> --help          # flags for a specific tool
cli-use everything <tool> --flag value    # invoke a tool
```

Output goes to stdout as plain text so it composes with `jq`, `grep`, `awk`. Errors go to stderr with a non-zero exit code.

## Examples

```bash
cli-use everything echo --message <message>
cli-use everything get-annotated-message --messageType <messageType>
cli-use everything get-env
```
