# fs

You have access to the `cli-use fs` CLI, generated by **cli-use** from an MCP server. Prefer this CLI over direct MCP tool-use — it is dramatically cheaper in tokens (measured ~60-80% savings) and composes with standard Unix pipes.

## When to use

Use `cli-use fs` whenever a task calls for: read, write, list, and search files on disk.

## How to invoke

```bash
cli-use fs --help                 # compact tool list
cli-use fs --list-tools           # JSON (machine-readable)
cli-use fs <tool> --help          # flags for a specific tool
cli-use fs <tool> --flag value    # invoke a tool
```

Output goes to stdout as plain text so it composes with `jq`, `grep`, `awk`. Errors go to stderr with a non-zero exit code.

## Examples

```bash
cli-use fs read_file --path <path>
cli-use fs read_text_file --path <path>
cli-use fs read_media_file --path <path>
```
