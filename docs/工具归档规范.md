# 工具归档规范

> 目的：让"工具放哪、属于哪个功能域、怎么被找到"有唯一答案。
> 起因：2026-09-15 之前工具目录有两套分组，247 个工具里 203 个（82%）挤在"其他"，
> 世界书每轮注入 19k 字符还看不出能力；按前缀规则重归并折叠 MCP 后，世界书降到 2.9k，未归类归零。
> 规范落地时间：2026-09-15。

## 一、新工具放哪里

| 类型 | 位置 | 注册方式 |
| --- | --- | --- |
| Python 工具（默认） | `tools/src/python/<name>.py` | `@tool(...)` + `tool_create`（走准入三关） |
| Go 工具（仅高并发/大文件/需单一二进制时） | `tools/src/go/` | `tool_create(language="go")`，go build 冒烟后注册 |
| MCP 服务工具 | `config/mcp.json` 的 servers | `mcp_connect` 写入配置 → `mcp_scan` 同步进注册表 |
| 一次性脚本 / 补丁脚本 | `workspace/tmp/` | 不注册、不进本体，用完即清 |
| 任务产物 / 快照 | `workspace/tasks/<任务名>/` | 生成物，可重生成，勿手改 |
| 方法论 / 记忆 | `memory_write` / `method_learn` | 落 data/ 记忆库 |

铁律：**不要往项目根目录随手丢文件**。凡"我以后还要看的东西"，要么进 `docs/`（规范文档），
要么进 `workspace/tasks/<任务>/`（产物），要么进 `tools/src/`（可复用工具）。

## 二、声明功能域（新建工具唯一必须记住的一条）

```python
@tool("weather_query", "查询天气", {参数schema}, group="网络")
def run(...): ...
```

漏声明 `group=` 不会报错，但会落进"其他"未归类，`tool_health_audit` 会告警。

## 四、判定优先级（单一真源）

`core/registry.py::ToolRegistry.resolve_group(name, declared)`，唯一的分类真源：

1. **工具源码里显式声明的 `group`**（最高优先，落在 registry.json 的条目 `group` 字段）
2. `_TOOL_GROUPS`（手工表，覆盖少量特例：cmd_run/sys_probe/ctx_search/word_count 这类无前缀可判的）
3. `_TOOL_PREFIX_GROUPS`（前缀规则，覆盖同族成批工具）
4. 都落空 → `"其他"`（= 未归类，`tool_health_audit` 告警）

世界书目录（`to_index_json`）、按能力检索（`tool_find`）、健康自检（`tool_health_audit`）全部调它，
**任何调用方不得自带第二份分组表**（这正是之前两套分组打架的根因）。

## 五、加一个新功能域怎么办

1. 在 `core/registry.py` 的 `_GROUP_ORDER` 里插入显示顺序（决定世界书里的排列位置）。
2. 归属方式二选一：新前缀 → 加进 `_TOOL_PREFIX_GROUPS`；少数无前缀的特例 → 加进 `_TOOL_GROUPS`。
3. 给该域工具在 `@tool(..., group="新域")` 里显式声明（可选，但更稳）。
4. 收尾三件套（见第七节）。

## 六、三个入口，各管一段

| 入口 | 形态 | 用途 |
| --- | --- | --- |
| 工具世界书 | 每轮注入 system prompt，~2.9k 字符 | 常驻速查：功能域 → 工具名(中文名) + 触发词；MCP 组折叠成一行 |
| `tool_find` | 主动调用 | 按能力/功能域/类型检索（多词打分，AND 落空自动放宽 OR）；`export_md=True` 导出可读目录快照 |
| `tool_health_audit` | 主动调用 | 僵尸/源文件缺失/hash 漂移/依赖缺失/MCP 配置错位/**未归类**告警 |

导出快照落 `workspace/tasks/tool_index/工具目录.md`（生成物，勿手改；改完工具重新导出）。

## 七、改动工具后的收尾三件套

1. 刷新注册表与被改工具的源码 hash：
   `reg = ToolRegistry(); reg.load(); reg.discover_builtin()`
   （注意：`load()` 返回 bool，不能链式写成 `ToolRegistry().load().discover_builtin()`，会报 AttributeError）
2. 重建本体完整性基线并复查：`core.integrity.rebuild_baseline()` → `core.integrity.check()`
3. 复查健康：`tool_health_audit(mode="scan")`，`healthy=true` 且 `unclassified=[]` 才算收工。

## 八、生成物 / 真源的界线

- 真源（手改）：`core/registry.py`（分组规则、中文名、关键词）、`tools/src/`、`config/mcp.json`
- 生成物（勿手改，可重生成）：`data/registry.json`（`discover_builtin` 重算）、
  `workspace/tasks/tool_index/工具目录.md`（`tool_find(export_md=True)`）、
  `workspace/tasks/tool_health/audit_report.json`（`tool_health_audit`）
